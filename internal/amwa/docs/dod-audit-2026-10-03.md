## Gap list → issues

### Node
- **N1** Go `-tags integration` suite under `internal/amwa/integration/` driving `dhs producer nmos serve` as a node that registers into the **nmos-cpp registry** (easy-nmos on dhs-tools) and is read back through its Query API + WebSocket; same against the Neuron's expectations where applicable.
- **N2** Fixture location/form: move the node fixture under `internal/amwa/testdata/integration-test/` (or record in this doc + ADR-0025 revisions why the NMOS resource graph is the fixture form) — decision, then one PR.
- **N3** Replay set: `testdata/protocol_types/<kind>/` (DNS-SD announce/browse, IS-04 registration POST/heartbeat/DELETE, Query GET/paginated/WS grain, IS-05 PATCH/activate, IS-07 WS + MQTT, IS-12 command/notification, IS-14), `fixtures/` (golden scenarios), `exports/`.
- **N4** BCP-003-01: serve an ECDSA certificate beside the RSA one so the recommended `TLS_ECDHE_ECDSA_*` suites are offered; OCSP stapling (`tls.Certificate.OCSPStaple` refreshed from the issuer's responder, EST/certmgr already holds the chain).
- **N5** IS-05 scheduled activation lands late: measure the scheduler against the clock injection, fix the deadline arithmetic, pin with a unit test on the fake clock.
- **N6** Fixture coverage of every optional feature the tool can exercise: IS-07 event sources tied to senders/receivers (WS + MQTT), IS-08 inputs with block constraints / no-reorder / forbidden routes, IS-11 video format + EDID-capable output + input without EDID + receiver `constraint_sets`, IS-14/MS-05 touchpoints, constraints hierarchy, datatype/property/runtime constraints, a non-standard class, deprecated properties; plus an `MS05_INVASIVE_TESTING=True` row in the catalogue and `IS11_REFERENCE_SENDER_*` config. Goal: zero `Could Not Test` that a fixture can turn into a scored test.

### Registry + mirror
- **R1** Go `-tags integration` suite: `dhs registry nmos serve` scored by the **nmos-cpp virtual node** registering into it (heartbeats, GC, re-registration after a 404) and an nmos-cpp-shaped Query client (pagination, `query.downgrade`, WS grains).
- **R2** Oracle pairing play + receipts: nmos-cpp node → dhs registry; dhs mirror ← nmos-cpp registry and → nmos-cpp registry; resource parity asserted from the oracle's own Query API.
- **R3** Replay set as N3 for the registry faces.
- **R4** DOD record: README coverage table + runbook sections for registry and mirror cite the suite receipts (ADR-0015 single source), this audit linked.

### Controller
- **C1** Spec client operations with no verb today: IS-05 **bulk** (`/bulk/senders|receivers`, the client only probes its presence), IS-08 channel-mapping client (`map` stage/activate), IS-12/MS-05 client (get/set property, invoke, subscribe), IS-14 client (device-configuration get/set/backup/restore), IS-11 client (constraints read/set), BCP-004-01 **capability match before connect** (refuse a route the receiver cannot decode, with the reason). `connect` already does immediate + scheduled (`--mode`, `--when`) and `--disconnect`.

- **C4** Committed plant fixture for offline controller replay (a registry snapshot the walk/watch tests read without a host).

# Corrections for vendor MIB defects that break name resolution.
#
#   MODULE  SYMBOL  PARENT  ARC  -- evidence
#
# Only what the vendor's OWN files, or the IETF's, prove belongs here. An arc guessed from
# a neighbour is an invented OID: the table would label a real device's
# objects with a name nobody defined, and nothing downstream could tell.
# Everything unprovable stays unresolved, and mibc reports it.
#
# When a vendor fixes a file, mibc reports the patch as "patch-stale";
# delete the line then.
